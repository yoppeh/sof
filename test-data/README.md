# test-data

Data shared by the tests, demos and benchmarks, which open it as _../test-data/name_ from their own directories (_../../test-data/name_ from _demo/_).

- _words.txt_: 263,533 English words, one to a line, from [Peter Norvig's n-gram data](https://norvig.com/ngrams/). Used where a program needs many distinct keys.
- _shakespeare.txt_: The Complete Works of William Shakespeare, [Project Gutenberg eBook #100](https://www.gutenberg.org/ebooks/100), as downloaded from <https://www.gutenberg.org/ebooks/100.txt.utf-8> on 2026-11-04 (the edition updated October 17, 2026): 5.6 MB of UTF-8 text with CRLF line endings, about 970,000 words. Used where a program needs real text, in which words and phrases repeat as they do in writing, such as [ngram](../demo/ngram/). The works are in the public domain in the United States; the file is kept unchanged, with the Project Gutenberg License at its end, under which it may be copied and given away.
- _JSONTestSuite/_: the parsing tests of [JSONTestSuite](https://github.com/nst/JSONTestSuite) by Nicolas Seriot, as of commit 1ef36fa (2024-11-22), with its README and license (MIT): in _test_parsing/_, 95 JSON texts a parser must accept (y_), 188 it must refuse (n_) and 35 it may do either with (i_). Used by the [sof_json](../sof_json/) tests. Kept unchanged.
- _csv-spectrum/_: [csv-spectrum](https://github.com/max-mapper/csv-spectrum) by Max Ogden, as of commit d30e80f (2024-07-04): 12 CSV files in _csvs/_ and the JSON each should read as in _json/_, with the project's readme and _package.json_, which gives its license as BSD-2-Clause (the project has no license file). Used by the [sof_csv](../sof_csv/) tests. Kept unchanged, though _location_coordinates_ isn't RFC 4180 and its JSON has a different phone number from its CSV; the tests allow for both.
- _toml-test/_: [toml-test](https://github.com/toml-lang/toml-test), the TOML project's own test suite, at release v2.2.0 (commit ce08da1, 2026-04-30), with its README and license (MIT): its _tests/_ directory, whose _files-toml-1.1.0_ lists the tests for TOML 1.1.0, 214 valid documents in _valid/_, each with the tagged JSON it must read as, and 467 invalid ones in _invalid/_ a parser must refuse. Used by the [sof_toml](../sof_toml/) tests. Kept unchanged.
- _config-data.ini_: a configuration file for the [sof_config](../sof_config/) tests.
- _ngram-data.txt_: a short line of letters.
